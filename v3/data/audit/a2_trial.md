# A2 TikTok 试拉记录（2026-10-03）

## 一、云端环境试拉结果

| 方式 | 结果 |
| --- | --- |
| yt-dlp按账号列视频（A0时已试） | 接口返回空内容，失败 |
| 无界面浏览器，桌面版主页，截取视频列表接口 | 主页资料可见，视频区显示“Something went wrong”，列表接口返回空内容或403 |
| 无界面浏览器，模拟iPhone访问 | 共5轮尝试，仅1次取得一页列表（约70KB，含完整字段），其余均为空内容；反复点击页面“Refresh”按钮12次无效 |
| 单条视频页（curl_cffi） | 正常。A0取得9条，本次取得2条，字段完整 |

结论：本环境中单条视频可读，账号视频列表被TikTok拦截，不能稳定取得。列表步骤改在作者本地运行，单条补全与汇总在云端进行。

## 二、字段核对（以 7395695233276595487、7426486234593217838 为例）

- 可得字段：发布时间（秒级）、文案、时长、播放、点赞、评论、分享、收藏、转发、背景音乐、是否置顶、是否广告、作者ID。
- 播放、点赞、评论、分享为4位有效数字的近似值（如28,100,000、3,800,000、127,100），收藏为精确值。相对误差小于0.05%，照原样记录，写作时在数据说明中交代。
- 两条视频的时长字段均为8秒，B1下载后用视频文件核对。
